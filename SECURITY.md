# Політика безпеки

## Підтримувані версії
Наразі активна підтримка та оновлення безпеки застосовуються до наступних версій проєкту:

| Версія | Підтримується |
| ------- | ------------- |
| main    | ✅            |

## Повідомлення про вразливості
Якщо ви знайшли вразливість у сфері безпеки цього проєкту, будь ласка, повідомте нас конфіденційно. **Не створюйте публічні Issues** для чутливих проблем безпеки.

Щоб надіслати звіт, перейдіть у вкладку **Security** цього репозиторію та натисніть **Report a vulnerability** (Приватне повідомлення про вразливість). Ми оперативно розглянемо ваше звернення та вживемо заходів щодо усунення загрози.
